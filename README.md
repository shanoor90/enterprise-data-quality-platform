# Enterprise Data Quality and Intelligence Platform

**CO3540 – Data Management Project**

## Project Overview

The Enterprise Data Quality and Intelligence Platform is a web-based application designed to improve the quality and reliability of structured datasets.

The platform aims to integrate automated data profiling, data validation, data cleaning, data quality assessment, and machine-learning-based anomaly detection.

## Main Features

- Automated Data Profiling
- User-Defined Data Validation
- Data Cleaning and Transformation
- Machine Learning-Based Anomaly Detection
- Data Quality Scoring and Visualization
- Data Lineage and Processing History
- Report Generation and Dataset Export

## Datasets

The project will investigate internationally recognized benchmark datasets and Sri Lankan public datasets.

Proposed benchmark datasets:
- UCI Adult Dataset
- UCI Bank Marketing Dataset

Proposed Sri Lankan data sources:
- Department of Census and Statistics
- Sri Lanka Open Data Portal
- Department of Agriculture

## Machine Learning Algorithms

- Isolation Forest
- Local Outlier Factor (LOF)
- One-Class SVM
- Z-score
- Interquartile Range (IQR)
